# 使用指南

[返回首页](../README.md) · [English](../README.en.md)

## 使用

1. 从 [Releases](https://github.com/qxpdev/Starveil/releases) 下载并运行 `Starveil-<版本>-win-x64.exe`。无需安装 Node.js。
2. 输入斗鱼房间号或直播间链接，点击“启动飘屏”。再次启动软件会沿用保存的开关状态。
3. 在设置中调整显示器、穿透、置顶、字体和消息保留时间；关闭鼠标穿透后可以移动窗口或拖动边缘调整大小。
4. “每日统计”可筛选日期、房间、用户，查看消费与礼物归属。“保存弹幕正文”需另外开启，才能按用户或关键词查证原文。
5. 在“礼物与抽奖”调整礼物排版、金额大小、独立透明度、官方礼物条和动画；在“边缘沉浸”调整统一间距、消息保留时间和礼物顶部额外停留。在“统计栏”开启模块并选择“始终显示”，可让边缘统计栏常驻。
6. 在“存储与缓存”选择缓存位置，保存并重启后生效。查看占用，点击“清理缓存…”并确认范围后执行；旧缓存不会在切换位置时自动删除。清理后图片与动画可重新获取，正在使用的缓存可能需要下次清理。

修改设置后，顶部显示“已保存”才表示写入成功。更新前请先从托盘退出旧版本；同时启动第二份新版程序只会唤回已有主面板。

## 主要功能

| 功能 | 行为 |
| --- | --- |
| 显示与窗口 | 显示器选择、透明背景、置顶、鼠标穿透、拖动缩放、边缘吸附与位置记忆 |
| 消息排版 | 右向左、上向下、下向上消息流与边缘沉浸；按实际内容高度换行与裁剪 |
| 字体与身份 | 字号、头像、字距、1.0–2.5 倍行高，昵称、用户等级、粉丝牌独立缩放 |
| 斗鱼表情 | 普通表情、数字编码、钻粉梗和房间表情；原始正文保留用于查询与导出 |
| 消息动效 | 同帧处理新增与到期，列表阻尼推进；动效可关闭并遵循系统减少动态效果 |
| 礼物栏 | 免费灰、缺价灰蓝、0.01–9.99 元青绿、10–99.99 元蓝、100–999.99 元紫、1000 元起金色 |
| 边缘统计栏 | 隐藏、随消息或常驻；顶部或底部，字号与透明度独立 |
| 抽奖礼包 | 分开显示投入金额、已开出价值与具体奖品；梦想巴士等活动通过官网配置识别 |
| 自动查价 | 普通礼物和奖励道具独立查价；价格后到时补算，缺价可手动补充 |
| 每日统计 | 默认开启；关闭只停止新增，已有历史保留 |
| 弹幕正文 | 默认关闭；开启后保存时间、房间、UID、昵称和原文，支持用户及关键词筛选 |
| 用户消费 | 汇总本机记录的普通送礼和抽奖投入；奖励价值单独列出 |
| Excel 导出 | 每日汇总、礼物明细、用户汇总、弹幕记录和统计口径五张工作表 |
| 存储管理 | 可设置缓存路径，重启生效；按类别清理当前和已知旧缓存，保护已保存的配置与用户数据 |

## 数据位置与迁移

Starveil（星幕）的数据固定保存在当前 Windows 账户，英文名称和 EXE 文件名改变后仍沿用原目录：

```text
%APPDATA%/douyu-danmaku-overlay/
  config.json              设置和手动礼物价格
  config.json.bak          上一份有效配置
  cache-paths.json          当前与已知旧缓存的位置清单
  statistics/              每日统计、用户与礼物记录
    danmaku/               按日期保存的弹幕原文
  cache/
    chromium/              网页资源、脚本及图形缓存与界面运行数据
    avatars/               主播头像
    emoticons/             房间表情目录
    logs/                  临时诊断日志
    crash-dumps/           崩溃诊断文件
```

- “打开配置目录”可以定位实际路径。只有明确的缓存子目录参与清理，不会删除整个 `cache/chromium` 或整个数据目录。
- 自定义缓存位置使用所选目录中的 `xingmu-cache`，结构与默认 `cache` 相同，另有 `.xingmu-cache.json` 归属标识。路径清单与标识不参与清理；不提供自动迁移已有缓存。恢复默认同样需要重启，旧目录中的非缓存内容保留。
- Chromium 的界面偏好文件、Local Storage 等运行状态不作为可清理缓存。旧版图片、图形和脚本缓存单独列为“旧版本遗留缓存”。
- 首次升级会尝试导入 EXE 同目录 `data/config.json`、`data.douyu-danmaku-overlay/config.json` 或旧账户位置的配置，原文件保留。已有新位置配置时优先使用它。
- 主配置损坏时尝试从 `.bak` 恢复，读取或保存失败会明确提示。
- 迁移到另一台电脑前，在两端完全退出程序，复制 `config.json` 和需要的 `statistics` 文件夹。目标电脑已有数据时先自行备份，避免覆盖。
- 便携程序运行时由打包启动器解压到临时目录，正常退出时尝试清除程序文件；被系统占用的个别文件可能残留。配置与历史始终存放在固定账户目录。
- 开发和测试可传 `--user-data-dir=绝对路径` 使用独立数据，避免修改真实配置。

## 统计与资源来源

- 只接受当前房间、正文非空的有效 `chatmsg`。外房间、无房间标识和启用过滤后缺少 `dms` 的疑似机器人分别排除；`dms=0` 有效，该字段不能完全区分真人与机器人。
- 消息合并、黑名单、显示时长和画面裁剪只影响显示，不丢弃已采集的查证正文。离线、断线或开启保存前的消息不能补回。
- 用户消费是本机记录的普通送礼金额与抽奖投入之和，不是平台交易账单。奖励和背包道具不推定为本次购买消费；未知价格显示待确认。
- 同一 UID、同一已确认活动的相邻投入短时汇总；有来源或唯一奖池依据的后到奖励最多等待 3 分钟。没有明确来源、UID 缺失或活动匹配不唯一时保留独立奖励，不猜归属。
- 普通礼物按 `gfid` 查价；`gpf=1` 的奖励按 `pid` 请求独立道具目录。贡献值、概率、展示占位价不当作人民币价值，抽奖投入不重复计入收到的奖励。
- 梦想巴士使用 `dream_bus_w.json` 的当前投入礼包与奖励 ID；通用变幻礼物读取 `pandora/config`。目录每小时刷新，新收到的未知 ID 自动补查，失败时重试。
- 普通表情映射来自斗鱼官网静态目录。钻粉和梗表情读取 `/japi/interact/comm/dfans/emojis`，房间表情读取 `/japi/livebiznc/web/roomemoji/list`。只使用合法斗鱼 CDN 图片地址，不执行远程脚本，不发送弹幕或礼物。
- 本地保存的统计和正文属于用户记录，缓存清理始终保留它们。旧版未记录的 UID、昵称和正文无法还原。
